# بوت إشارات البورصة المصرية (EGX TradingView Signal Bot)

نظام متكامل لتوزيع إشارات التداول من منصة **TradingView** عبر الويب هوك (Webhook) إلى مشتركي **تليجرام** مع نظام فلترة ذكي لكل مستخدم وتخصيص الأسهم المفضلة والفريمات الزمنية.

---

## 🌟 المميزات الرئيسية
1. **فلترة مخصصة لكل مستخدم (User-level Filtering):**
   - كل مستخدم يختار أسهمه المفضلة من البورصة المصرية (مثل COMI، TMGH، HRHO.. إلخ) من خلال أزرار تفاعلية سهلة.
   - يختار الفريمات الزمنية التي يرغب بمتابعتها (`15m`، `30m`، `1h`، `4h`، `1D`، `1W`).
   - الإشارة تصل **فقط** للمستخدمين الذين حددوا نفس السهم ونفس الفريم الزمني.
2. **إدارة المشتركين والصلاحيات (Admin Approval):**
   - عند انضمام أي مستخدم جديد، يتم تنبيه المدير تلقائياً بزر [موافقة] أو [رفض].
   - لا تصل أي إشارة لمستخدم حتى يقوم المدير بتفعيله.
3. **قائمة مدمجة للبورصة المصرية:**
   - تضم أكثر من 40 من كبرى شركات EGX30 و EGX70 مع أسمائها العربية.
   - إمكانية إضافة أي سهم جديد بسهولة.
4. **تنبيهات احترافية منسقة:**
   - نوع الإشارة (شراء 🟢 / بيع 🔴).
   - سعر الدخول، الأهداف المقترحة، ووقف الخسارة.
   - التوقيت المحلي بدقة بتوقيت القاهرة.
5. **لوحة تحكم للمدير داخل التليجرام:**
   - إحصائيات المشتركين، إدارة الطلبات، وإضافة أسهم جديدة.

## 🚀 طريقة التثبيت والتشغيل

### 1. إعداد ملف الإعدادات `.env`
افتح ملف `.env` وقم بملء البيانات التالية:
```env
TELEGRAM_BOT_TOKEN=ضع_توكن_البوت_هنا
ADMIN_USER_ID=ضع_معرفك_على_تليجرام_هنا
WEBHOOK_PORT=8000
WEBHOOK_SECRET=egx_secret_token_123
TIMEZONE=Africa/Cairo
```
> للحصول على التوكن: افتح [@BotFather](https://t.me/BotFather) في تليجرام وأنشئ بوتاً جديداً عبر الأمر `/newbot`.
> لمعرفة الـ ID الخاص بك: تحدث مع [@userinfobot](https://t.me/userinfobot) في تليجرام.

---

### 2. تشغيل النظام
قم بتشغيل ملف `main.py`:
```powershell
python main.py
```
سيبدأ البوت بالعمل فوراً لاستقبال مستخدمي تليجرام، وسيعمل خادم الويب هوك على المنفذ `8000`.

---

### 3. ربط الويب هوك مع TradingView
لكي يتمكن TradingView من إرسال التنبيهات إلى جهازك، يحتاج إلى رابط عام بصيغة `HTTPS`. يمكنك استخدام أداة مجانية مثل:

#### خيار أ: باستخدام Cloudflare Tunnel (مجاني وبدون حساب):
```powershell
cloudflared tunnel --url http://localhost:8000
```

#### خيار ب: باستخدام Ngrok:
```powershell
ngrok http 8000
```

سيعطيك رابطاً مثل:
`https://abc-123.ngrok-free.app`

رابط الويب هوك الذي ستضعه في TradingView سيكون:
`https://abc-123.ngrok-free.app/webhook`

## 🧪 اختبار الإشارات محلياً (Test Simulation)
يمكنك اختبار وصول الإشارات في أي وقت بتشغيل سكريبت الاختبار:
```powershell
# إرسال إشارة تجريبية لسهم التجاري الدولي COMI على فريم ربع ساعة
python test_webhook.py COMI 15m

# أو لأي سهم آخر
python test_webhook.py TMGH 1h
```

## 📱 أوامر البوت المتاحة للمستخدمين:
- `/start` - فتح القائمة الرئيسية للبوت.
- `/stocks` - إدارة قائمة الأسهم المفضلة.
- `/timeframes` - إدارة الأطر الزمنية.
- `/recent` - استعراض آخر الإشارات المسجلة.
- `/help` - دليل الاستخدام.
